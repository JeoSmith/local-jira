# 키보드 단축키와 커맨드 팔레트

## 사용자 스토리 (User Story)

> **As a** 하루에도 여러 번 이슈를 오가는 개발자·PO,
> **I want** 키보드만으로 팔레트를 열어 이슈를 찾아가고 자주 쓰는 명령을 실행하기를,
> **so that** 이슈 1건 생성·조회에 드는 시간이 마우스로 화면을 헤매는 비용에 잡아먹히지 않는다(성공 지표: 이슈 1건 생성 ≤ 30초).

## 인수 조건 (Acceptance Criteria)

- [ ] Given 백로그·보드·이슈 상세·스프린트·설정 중 어느 화면이든, When 팔레트 단축키를 누르면, Then 커맨드 팔레트가 열리고 검색 입력에 포커스가 간다. *(§8 화면 목록)*
- [ ] Given 팔레트가 열림, When 텍스트를 입력하면, Then **이슈 결과**(표시 키·제목·본문 전문 검색)와 **명령 결과**(화면 이동, 신규 이슈, 필터 적용)가 서로 구분된 그룹으로 표시된다. *(R4 FTS5)*
- [ ] Given 팔레트에서 이슈를 선택, When Enter를 누르면, Then `/issues/:key`로 이동한다. *(§8)*
- [ ] Given 재키잉으로 `LJ-13`을 `former_keys`에 갖게 된 이슈, When 팔레트에 `LJ-13`을 입력하면, Then 현재 키 보유 이슈와 옛 키 보유 이슈가 **구분되어** 결과에 나온다. *(AC25, R26)*
- [ ] Given 5,000건 데이터셋, When 팔레트에서 검색어를 입력하면, Then 검색·필터 API가 **p95 ≤ 300ms**를 만족한다. *(N1, AC13)*
- [ ] Given 권한이 없는 사용자(예: `issue:delete`가 없는 토큰·역할), When 팔레트를 열면, Then 실행할 수 없는 명령은 노출되지 않거나 비활성화된다 — 눌러서 403을 받는 경험을 만들지 않는다. *(§6.4, AC7)*
- [ ] Given 제목·설명 등 **텍스트 입력 필드에 포커스**가 있음, When 단일 문자 단축키에 해당하는 글자를 입력하면, Then 단축키가 발동하지 않고 글자가 그대로 입력된다.
- [ ] Given 팔레트가 열림, When `ESC`를 누르면, Then 팔레트가 닫히고 포커스가 열기 직전 요소로 돌아간다.
- [ ] Given 팔레트가 열림, When 키보드만으로 조작하면, Then 위/아래로 항목을 이동하고 Enter로 실행할 수 있으며, Tab 포커스가 팔레트 밖으로 새지 않는다(포커스 트랩).
- [ ] Given 백로그·보드 리스트 화면, When 단축키로 신규 이슈를 만들면, Then 툴바 우측(`ml-auto`)의 **[신규] 버튼과 동일한 경로**를 탄다. *(§8, HPMS `design.md §6.1`)*
- [ ] Given 어느 화면이든, When 도움말 단축키를 누르면, Then **현재 화면에서 사용 가능한 단축키 목록**이 표시된다.
- [ ] Given 라이트/다크 테마, When 팔레트와 단축키 도움말을 열면, Then 두 테마 모두에서 shadcn/ui + lucide 규약대로 렌더된다. *(§8)*
- [ ] Given 네트워크가 없는 환경, When 팔레트로 검색·이동·생성을 하면, Then 전부 정상 동작한다. *(N4)*
- [ ] Given 팔레트를 여닫고 명령을 실행, When 활동 타임라인·이벤트를 확인하면, Then 팔레트 사용 자체는 이벤트를 만들지 않고, 실행된 도메인 명령만 N7 범위대로 기록된다. *(§9 N7 — 조회·검색은 감사 제외)*

> ⚠ 미정: **실제 키 바인딩** — 팔레트 열기, 항목 이동, 신규 이슈, 도움말 등 각 조합을 PRD가 정하지 않는다. macOS/Linux 양쪽(N8)에서 브라우저·OS 기본 단축키와 충돌하지 않는 조합 선정이 필요하다.
> ⚠ 미정: 사용자별 **키맵 커스터마이즈** 지원 여부와 저장 위치(`.local/`은 기기 고유·백업 비대상, D5).
> ⚠ 미정: 팔레트에서 **쓰기 명령**(상태 전이·담당자 변경·스프린트 이동)까지 허용할지. 허용하면 §5.2 전이표, §6.1 claim↔전이 결합, §5.4 `If-Match` ETag를 팔레트 경로에서도 지켜야 한다.
> ⚠ 미정: 접근성 기준의 수준 — 스크린리더 대응, ARIA 역할, 대비비 기준을 PRD가 명시하지 않는다.
> ⚠ 미정: 팔레트 검색이 **격리(`INVALID`) 엔티티**를 결과에 보여줄지 — §5.6은 "일반 조회·집계에서 제외"라고만 한다.
> ⚠ 미정: 최근 방문 이슈·최근 실행 명령의 이력 표시 여부와 그 저장 위치.
