# 데스크톱 앱 만들기 (macOS)

터미널을 열지 않고 아이콘 하나로 보드를 여는 방법이다. `localjira serve`를 치고 브라우저에
주소를 넣는 세 단계를 한 번의 클릭으로 줄인다.

**Electron이나 Tauri를 쓰지 않는다**(S6-D6). `.app`은 plist와 실행 파일이 든 디렉터리일 뿐이라
`fs`로 쓸 수 있고, 창은 이미 깔려 있는 Chromium 계열 브라우저의 `--app` 모드를 쓴다. 의존성
0개(S2-D1)를 그대로 둔 채 창을 얻는 방법이다.

## 만들기

```
node scripts/make-app.ts --repo <보드가 있는 저장소> [--port 4173] [--out ./dist] [--name "Local Jira"]
```

예:

```
node scripts/make-app.ts --repo ~/orca/projects/project-local-jira --out ~/Applications
```

- `--repo`는 **필수**다. 어느 보드를 열지에 기본값은 없다. `.localjira`가 없으면 아무것도 쓰지
  않고 거부한다.
- `--out`은 기본이 `./dist`다. `~/Applications`로 옮기면 런치패드와 스포트라이트에 나온다.
- `--name`으로 이름을 달리 주면 **보드마다 앱을 하나씩** 만들 수 있다.
- 아이콘은 그 자리에서 그려서 만든다(`node:zlib`로 PNG를 쓰고 `iconutil`로 icns). macOS가 아니면
  아이콘만 건너뛰고 그 사실을 말한다.

## 동작

| 상황 | 결과 |
|---|---|
| 서버가 꺼져 있을 때 앱 실행 | 서버가 뜨고, 탭·주소창 없는 창에 보드가 뜬다 |
| 앱 종료(⌘Q) | **앱이 띄운 서버도 멈춘다** |
| 터미널에서 이미 `serve` 중일 때 앱 실행 | 새로 띄우지 않고 붙는다. 앱을 종료해도 **그 서버는 살아 있다** |
| 서버가 못 뜰 때 | 알림으로 알리고 로그 위치를 말한다. 빈 창을 보여주지 않는다 |
| Chromium 계열 브라우저가 없을 때 | 기본 브라우저로 열린다. 창에 묶인 수명이 없어 서버를 죽이지 않는다 |

**창을 닫는 것과 앱을 종료하는 것은 다르다.** 창만 닫으면 앱은 살아 있다 — 맥의 표준 동작이고,
정리는 종료(⌘Q) 시점에 일어난다.

찾는 순서는 Chrome → Edge → Brave → Chromium이다.

## 업데이트

번들은 저장소의 `src/cli.ts`를 가리킨다. **`git pull`이 곧 업데이트다** — 앱을 다시 만들 필요가
없다. 다시 만들어야 하는 경우는 보드 경로나 포트를 바꿀 때뿐이다.

## 한계

- **macOS 전용.** `.app`은 맥 형식이다.
- **서명·공증하지 않았다.** 자기 기계에서 만들어 쓰는 것이 전제다. 남에게 파일로 넘기면 받는
  쪽에서 Gatekeeper 경고를 보게 되고, 그때는 서명이 필요하다.
- **Node가 설치돼 있어야 한다.** 런처가 `node`를 찾아 서버를 띄운다.

## 로그

서버 출력은 `$TMPDIR/local-jira-app.log`에 쌓인다. 창이 안 뜨거나 알림이 떴을 때 먼저 볼 곳이다.
