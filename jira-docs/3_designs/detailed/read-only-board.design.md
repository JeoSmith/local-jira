# 읽기 전용 보드 초기 화면

백엔드 구현을 계속하기 전에 현재 파일·인덱스·인증·SSE 경로를 사람이 직접 확인할 수 있는 최소 화면을 제공한다.
이 화면은 R7 전체 구현이 아니라 코어 동작을 관찰하기 위한 얇은 UI다.

## 범위

- `/`에서 로그인하고 현재 계정 이름을 확인한다.
- `/issues`의 결과를 상태 컬럼으로 묶고, 컬럼별 건수·포인트와 카드의 키·제목·유형·담당자·포인트·라벨을 표시한다.
- 프로젝트 필터와 빈 상태·오류·세션 만료 상태를 제공한다.
- `/stream`의 변경 이벤트를 받으면 이슈 목록을 다시 조회한다.
- 화면에서는 이슈를 생성·수정·전이·삭제하지 않는다.

## 구현 결정

현재 서버의 Node.js 표준 라이브러리 무의존 원칙을 유지하기 위해 `src/web`의 HTML·CSS·JavaScript를
동일 출처에서 정적으로 제공한다. 정적 경로는 명시적인 allowlist만 사용하며 인증 API보다 먼저 제공한다.
도메인 API와 SSE는 기존과 동일하게 세션 인증이 필요하다.

이 초기 화면은 ACTIVE 스프린트 스코프, actor·claim·run 배지, 드래그 전이 등을 포함하지 않는다.
해당 기능은 `r07a-board-columns-cards.md`와 후속 스토리에서 데이터 계약이 갖춰진 뒤 구현한다.
